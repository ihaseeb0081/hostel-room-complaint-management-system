# Hostel Room & Complaint Management System

## 📌 Project Overview

The Hostel Room & Complaint Management System is an ICT-based semester project developed to provide a digital approach for reporting, tracking, and managing hostel-related complaints.

The project was developed as part of the Fundamentals of ICT Lab course by first-semester students of the Artificial Intelligence Department at Pak-Austria Fachhochschule: Institute of Applied Sciences and Technology (Pak-IAST).

## 🎯 Objectives

- Provide a digital platform for students to submit hostel-related complaints.
- Maintain organized complaint records.
- Track complaint status such as Pending, In Progress, and Resolved.
- Improve communication between students and hostel administration.
- Analyze complaint data to identify common hostel issues.
- Apply practical ICT tools to a real-life problem.

## ✨ Key Features

- Student login system
- Admin login system
- Digital complaint submission form
- Complaint status tracking
- Admin dashboard
- Complaint statistics
- Organized complaint records
- Status updates for complaints
- Responsive and user-friendly interface

## 🌐 Website Features

The website provides separate functionality for students and administrators.

### Student

Students can:
- Log into the system
- Submit a hostel complaint
- Provide room and complaint details
- View their submitted complaints
- Track complaint status

### Administrator

Administrators can:
- View all complaints
- View complaint statistics
- Monitor complaint status
- Change complaints to In Progress or Resolved

## 📂 Project Components

- `index.html` — Main website containing the HTML, CSS, and JavaScript implementation.
- Excel data — Used for organizing and analyzing complaint data.
- MS Access — Used for structured database design and complaint records.
- MS Word — Used for project documentation.
- MS PowerPoint — Used for project presentation.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Use the demo credentials provided in the website to explore the student and admin interfaces.
